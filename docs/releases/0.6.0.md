# Glint 0.6.0 · Preview / 预览版

查英文单词可以直接开始，无需配置模型；导入自己的 MDX 词典，按习惯安排查询顺序。

Look up English words offline without configuring a model, and bring your own MDX dictionaries.

## 本次更新 / What's new

- **离线单词释义**：内置 ECDICT 精简英汉词库，提供释义、音标和词形变化。未收录的词与句子仍使用模型，也可在卡片中点击「AI 翻译」。/ A compact ECDICT dataset provides definitions, phonetics and inflections. Unknown words and sentences use your configured model; choose AI translation to bypass a dictionary result.
- **自定义词典**：「词典」页支持导入 MDX 1.x / 2.x 文字词典，启停、排序和移除立即生效。按列表顺序查询，再回退内置词库；仅适用于内置「翻译」动作。/ Import, enable, reorder and remove MDX 1.x / 2.x text dictionaries in Dictionary settings. Imported dictionaries take priority over ECDICT; lookup applies only to the built-in Translate action.
- **保护截图剪贴板**：复制取词不再预先清空剪贴板，也不会用旧文本覆盖后续截图或手动复制；历史清理时释放系统剪贴板。/ Copy capture no longer pre-clears the clipboard or overwrites a later screenshot or manual copy. History cleanup runs without holding the clipboard lock.
- **浮条交互修复**：修正 Windows 偶发点击无响应；等待资源、实际尺寸和首帧就绪后显示，处理不同缩放屏幕间的尺寸变化，并补充显示诊断日志。/ Fix discarded Windows toolbar clicks and wait for resources, actual viewport size and first native paint before presentation, including display-scale changes. Add presentation diagnostics.
- **界面细节**：统一浮条和结果卡片间距，修正窄卡片底部按钮溢出。/ Refine toolbar and result-card spacing and keep controls within narrow cards.
- **Linux 源码预览**：加入 X11 / Wayland PRIMARY 取词、XWayland 浮条和本地 AppImage/tar 打包支持，详见 [Linux 说明](../LINUX.md)。本次 Release 下载仍为 Windows x64。/ Add Linux PRIMARY capture, XWayland toolbar support and local AppImage/tar packaging; see the [Linux guide](../LINUX.md). Release downloads remain Windows x64.

## 更新与数据 / Updating and data

更新前请从托盘菜单完全退出 Glint。已有动作、取词方式、模型配置和记录保留；首次升级默认开启「单词优先查词典」，可在「词典」页关闭。

Quit Glint from the tray before updating. Existing actions, capture preferences, model configuration and records are preserved. Prefer dictionary for words is enabled on first upgrade and can be disabled in Dictionary settings.

导入词典保存在本地数据目录中；移除只删除导入副本，保留原文件。MDX 3、密码保护、MDD 图片与发音和原词典样式暂不支持。词典不执行脚本或加载外部资源，未命中时才将文字发送到配置的模型服务。

Imported dictionaries stay in the local data directory. Removal deletes only the imported copy. MDX 3, password protection, MDD images/audio and original styling are not supported. Dictionary scripts and external resources are not executed; a lookup miss falls back to your configured model service.

Portable 和安装版共享 AppData 中的配置和记录。当前为未签名预览版，无自动更新；不同应用的取词兼容性仍可能不同。

Portable and installed editions share AppData settings and records. This is an unsigned preview without automatic updates; capture compatibility varies by application.
